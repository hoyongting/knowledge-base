# 📚 我的个人知识库

> 把零散的想法，沉淀成可以复用的知识。

这是我的个人知识库，用来记录技术探索、读书心得、生活感悟，以及一切值得留下的东西。

## 📂 目录结构

| 目录 | 用途 |
|------|------|
| `notes/技术/` | 技术笔记、踩坑记录、解决方案 |
| `notes/读书/` | 读书笔记、书摘、思考 |
| `notes/生活/` | 生活随笔、记录、感悟 |
| `topics/` | 按主题整理的专题文章 |
| `templates/` | 笔记模板，方便快速新建 |

## 📝 如何新增一篇笔记

1. 从 `templates/` 复制对应的模板
2. 放到 `notes/` 下合适的分类目录
3. 文件名格式：`YYYY-MM-DD-标题.md`
4. 在 `index.md` 里补上链接
5. 提交到 Git，慢慢积累

## 🔖 命名约定

- 笔记：`2026-11-20-GitHub连接排障记.md`
- 专题：`主题名.md`
- 标签写在文件开头的 front matter 里

## 💡 理念

- **记录即思考**：写下来才算真正理解
- **结构化沉淀**：零散信息 → 分类 → 专题 → 体系
- **持续迭代**：知识库不是一次建成的，是长出来的
